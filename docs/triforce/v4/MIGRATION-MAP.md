## Migration sequence

1. Freeze old reference and current-failure evidence.
2. Introduce v4 modules beside v3 behind an explicit development flag.
3. Land `GasperVolumeMesh` and surface-attachment API.
4. Land `FaceRig2D + FacePatch3D`.
5. Rewire Look and GSAP to v4.
6. Rewire Wispwalker Studio controls to v4.
7. Pass Wispwalker gates.
8. Move embodiment projections to v4.
9. Migrate 20s take.
10. Delete/disable v3 body writers from normal runtime.
11. Remove FormMaster as normal runtime dependency only after parity evidence is captured.

## No-big-bang rule

The refactor is staged and continuously runnable. A worker may not delete the only working reference path before its replacement has objective and visual evidence.
