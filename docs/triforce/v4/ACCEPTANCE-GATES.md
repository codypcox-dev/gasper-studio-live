# Gasper v4 Acceptance Gates

**Id:** `GASPER-V4-GATES-001`

## Gate philosophy

Objective tests prevent false landings. Owner visual review prevents technically valid but visually wrong landings. Both are required.

## G0 — Reference integrity

PASS when:
- v6.5.5 Wispwalker reference is reproducible;
- canonical 512 front contour fixture is frozen;
- face semantic fixture/path reference is frozen;
- current pressed-mint baseline is captured;
- evidence commands are deterministic.

## G1 — Wispwalker volume

Objective:
- one watertight manifold;
- no non-manifold edges;
- no visible self-intersection in accepted neutral range;
- canonical front contour within agreed subpixel/normalized tolerance;
- 360° orbit uses actual geometry;
- no component split;
- no alternate silhouette writer;
- stable semantic attachment map.

Visual:
- immediately reads as Wispwalker from front;
- profile is an authored organism, not a candy/mint/capsule;
- lower cleft does not cut through the whole body;
- feet are continuous load-bearing lobes;
- crown/body remain one mass;
- 3/4 views feel dimensional, not card-like.

## G2 — Vector face

Objective:
- canonical source remains cubic/vector data;
- no raster face texture required;
- FacePatch3D remains attached under deformation;
- front/45/90 visibility is depth/occlusion driven;
- blink closes geometry;
- fixture interpolation is deterministic.

Visual:
- front face is recognizably the accepted Gasper face;
- no floating/sliding;
- pupil-less gaze reads through shape/orientation;
- mouth retains mature/subtle expressiveness;
- no cartoon eyebrow regression.

## G3 — Look/material

Objective:
- normals derive from live surface;
- light motion is view/world coherent;
- no baked view-specific fake body;
- internal energy does not rewrite silhouette independently.

Visual:
- dark-pearl identity returns;
- moving key/spec proves actual curvature;
- interior light supports rather than obscures face/form.

## G4 — Living motion

Objective:
- GSAP semantic tracks drive local numeric state;
- interruption begins from current evaluated state;
- no React/MCP/REST/browser-automation per-frame path;
- deterministic scrub/replay;
- gait has explicit contact/load states.

Visual:
- breathing does not puff identity away;
- blink/gaze feel alive;
- weight transfer is visible;
- true 3/4 body motion accompanies steps;
- settle/viscosity feels continuous and restrained.

## G5 — Eight embodiments

For each embodiment:
- same semantic organism;
- no mesh identity swap in normal runtime;
- front/45/profile/back/full-orbit atlas;
- characteristic motion;
- transition in/out;
- owner identity acceptance.

## G6 — Studio truth

PASS when:
- every visible control has a live binding;
- semantic edits update the same v4 organism;
- undo/redo exact;
- save/open exact;
- keyframes/curves deterministic;
- compare truly renders comparison;
- raw render mesh is not the default user model;
- MCP semantic commands are transactional and undoable.

## G7 — 20s 3D scene

PASS when:
- scene is recreated from editable v4 tracks;
- no pre-rendered body substitution;
- face remains vector/surface-bound;
- gait/weight/orbit/material are genuinely 3D;
- story beats preserve the accepted vector-side intent;
- owner judges it as the same Gasper, improved spatially.

## Promotion matrix

`PASS` requires all applicable objective checks plus owner visual acceptance for identity-sensitive gates.

Allowed intermediate states:
- `GREEN-OBJECTIVE / PENDING-VISUAL`
- `RED-OBJECTIVE`
- `RED-VISUAL`
- `BLOCKED-TOOLING`

Forbidden state:
- `PASS` based only on tests/builds/model judgment.
