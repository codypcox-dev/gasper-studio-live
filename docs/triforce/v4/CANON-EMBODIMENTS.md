# CANON — Gasper v4 Embodiments

**Id:** `GASPER-V4-EMBODIMENTS-001`

## Identity law

There are eight canonical embodiments and one Gasper. An embodiment is a reversible projection of the same semantic organism, not a preset that swaps to an unrelated mesh.

Canonical set:

1. Presence
2. Wispwalker
3. Comet Familiar
4. Dormant Singularity
5. Dormant Orbit
6. Halo Crown
7. Lantern Geist
8. Low Orbit

## Shared invariant set

Every embodiment preserves a traceable mapping for:

- mass continuity;
- surface material family;
- face semantics where the face is active;
- internal-energy provenance;
- structural rig correspondence;
- 25×40 semantic field correspondence;
- motion/viscosity semantics;
- identity timing and restrained asymmetry.

An embodiment may suppress a face, concentrate mass, flatten, elongate, trail, or orbit energy, but it may not instantiate a second disconnected character identity.

## Morph contract

Morphs start from the currently evaluated state and preserve current velocity/lag where relevant.

- no snap through canonical poses;
- no mesh swap;
- no topology swap in ordinary runtime;
- no detached tail/halo/core object becoming identity authority;
- transitions are reversible unless a behavior route explicitly enters a dormant memory state.
