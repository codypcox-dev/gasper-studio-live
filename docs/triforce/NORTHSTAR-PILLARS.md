## Regional τ (first field)

`sin(θ)` is height: 0 = crown, 1 = feet.

```
τ(θ) = crown ── waist ── foot
small τ = solid (catches now)
large τ = gel (lags)
```

Owner default: waist-down almost solid (`foot ≈ 0.04`, `waist ≈ 0.08`), gel at the crown (`crown ≈ 0.28`). Plant/swing may still stiffen a planted foot below the field. Mute Voigt = passthrough (hard snap).
